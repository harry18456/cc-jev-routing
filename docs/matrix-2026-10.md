# The matrix, October 2026

jev-routing 0.2.0 on 15 coding tasks, four session models and six settings, three runs each. Numbers here are the ones in [`matrix-2026-10.json`](matrix-2026-10.json).

## How it was run

- 396 headless `claude -p` runs (Claude Code 2.1.302, first-party API, 2026-10-17/18), US$229 in all.
- Each run: a fresh copy of a small Python project (a shop backend), one prompt, no CLAUDE.md, no other plugins, hooks or MCP servers (`--setting-sources local --strict-mcp-config --disable-slash-commands`, `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`). `--safe-mode` would be simpler, but it also turns off the hooks of a `--plugin-dir` plugin.
- Graded by hidden unit tests the model never saw (the three lookup tasks by their answer). Each hidden suite was checked first: it fails on the starting code and passes on a reference solution.
- Sessions: haiku and sonnet at medium effort (so the effort can move both ways), opus and fable at max effort.
- Settings: plugin off, `down-only`, `down-only` + effort switch, `both`, `both` + effort switch, `none` + effort switch (`none` without the switch does nothing).
- Settings that run the same model at the same effort for a task share one set of runs: 132 distinct executions instead of 360. Jev's verdict for each prompt was probed first; in the runs it matched the plan every time but once (one Jev error, which kept the session's setting as designed).
- Cost is what Claude Code reported. One run stopped at the time limit; its cost comes from the plugin's per-step usage log.

## Limits

- One prompt per session: no run paid the cache rewrite a multi-turn session pays when it switches models (README, *What it saves*).
- The tasks were too easy for haiku to fail, so routing up could only add cost here. A harder supplement (a TOML parser checked against `tomllib`, a SQL engine checked against SQLite) was prepared and not run.
- The runs made only 3 subagent decisions in all, so subagent routing is not measured here.
- Jev: 216 decisions in the runs, 1 error, median 257 ms.
